🌱 UMEED 1.0

A Digital Mental Health Support System
UMEED 1.0 is an early-stage mental wellness platform focused on providing AI-powered emotional support and basic mental health resources in a simple, accessible way.

🎯 Problem Statement

Mental health support is often:

❌ Difficult to access

❌ Expensive

❌ Surrounded by stigma

❌ Lacking early intervention

Many students and young adults struggle silently without a safe space to talk or seek guidance.

💡 Solution: UMEED 1.0

UMEED 1.0 introduces a local AI-powered chat-based support system that allows users to:

Express emotions safely

Receive supportive, non-judgmental responses

Access basic mental wellness guidance

This version focuses on core functionality and feasibility, serving as the foundation for future scalable versions.

✨ Key Features

🤖 AI Chat Support (Ollama-based)
Provides empathetic and conversational emotional support using a locally hosted LLM.

💬 Safe Interaction Environment
Users can interact with the system privately without fear of judgment.

📚 Basic Mental Health Awareness
Offers general guidance and supportive responses for stress, anxiety, and emotional concerns.

🧪 Prototype for Hackathons & Research
Designed as a functional MVP to validate the idea and technical approach.

🖥 Local Setup & Execution
1️⃣ Start Ollama Model

Make sure Ollama is installed and running.

ollama run llama3

2️⃣ Run the Application
python run.py (pip install -r requirements)


That’s it ✅
No complex setup required.

🛠 Tech Stack

Language: Python

AI Model: Ollama llama3

Backend: Python (Flask / minimal server)

Deployment: Local execution

Focus: Privacy-first, offline-friendly AI chat
